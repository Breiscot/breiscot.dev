A bit about me

I'm a developer and game maker from Italy. I spend my time between Godot projects, web experiments and open source code — I like building things that people can actually touch: games you can play in the browser, tools you can fork, sites that work without a framework.

I work for Hack Club, and some of my projects were born from community initiatives like MilkyWay. Everything you see on my sites is open source — feel free to read the code.
